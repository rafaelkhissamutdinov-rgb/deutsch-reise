# PROGRESS — Deutsch-Reise

Журнал работы (для следующего запуска: сначала прочитать этот файл).

## Сделано
- **Этап 1 — каркас** (`app-beta/`): роутер на hash с историей браузера, липкая кнопка «zurück», 7 тем по дням недели
  (светлая + тёмная), живой фон на canvas (пятна, частицы, параллакс по пальцу и наклону), 3D-эмодзи Fluent
  (выпрыгивают, плавают в 3 слоях, подпрыгивают по тапу), карта маршрута, город, паспорт со штампами (выцветают),
  прогресс в localStorage, экспорт/импорт кодом `DR1.…`, отмена последнего шага, сброс с подтверждением,
  Service Worker (офлайн), шрифты Nunito/Literata и иконки Lucide локально.
- **Этап 2 — движок**: упражнения choice / tf / gap / order (тап + перетаскивание) / table, серия с итогом и
  разбором ошибок; SRS-карточки (память = e^(−дни/стабильность)), ввод слова, артикли на скорость, список слов.
  Hören (Web Speech API, скорость, субтитры, диктант с подсветкой, shadowing), Lesen (тап по слову → перевод →
  в карточки), Schreiben (задание, Redemittel, структура, образец, чек-лист, счётчик слов, промпт для ИИ),
  Dialoge (ветвящиеся), карточки Sprechen.
- **Контент A1**: Hamburg, Berlin, Leipzig — 691 слово, 15 тем грамматики, 183 упражнения, 6 диалогов,
  6 текстов, 6 аудирований, 4 задания на письмо, 9 карточек Sprechen, 3 мини-теста.
- **Тесты** (`npm test`): данные, все экраны 390 px светлая/тёмная, упражнения, экспорт/импорт/отмена, SRS,
  контраст (основная кнопка ≠ зелёная, ΔE ≥ 35; текст ≥ 7:1), офлайн, кнопка «назад».

## Решения
- Источник приложения = `app-beta/`. Релиз: `python3 build.py --release` копирует в `app/` (только после «регаем»).
- Контент: `content-source/vocab/*.txt` (строчный формат) + `content-source/units/*.yaml`; формат — `content-source/FORMAT.md`.
- `build.py` при каждой сборке ставит версию кэша SW = хеш файлов.
- Карта схематичная (позиции вручную в `build.py`, `MAP_POS`), чтобы города не налезали друг на друга.

- **Korrektorat A1** сделан: качество немецкого хорошее; исправлен перевод Erdgeschoss, из Leipzig убраны 36 слов-дублей
  (итого A1 = 655 слов); `build.py` теперь падает на дублях слов между юнитами.
