# PROGRESS — Deutsch-Reise

Журнал работы (для следующего запуска: сначала прочитать этот файл).

## Где что
- Приложение: `app/` → https://rafaelkhissamutdinov-rgb.github.io/deutsch-reise/app/ (корень сайта перенаправляет туда).
  Беты больше нет (решение владельца 12.10): всё сразу в `app/`. Старый адрес `app-beta/` перенаправляет на `app/`
  и снимает старый Service Worker.
- Устанавливается как приложение (PWA): кнопка «App installieren» на главной (Android/Chrome/Edge — системный диалог,
  iPhone — инструкция «На экран Домой»). Chromium: ошибок установки нет.
- Контент: `content-source/vocab/*.txt` + `content-source/units/*.yaml` (формат — `content-source/FORMAT.md`),
  модельные тесты — `content-source/pruefung/*.yaml` (формат — `content-source/pruefung/FORMAT.md`).
- `python3 build.py` — проверка + генерация `app/data/*.js` + новая версия кэша SW. `--check` только проверка,
  `--only ID` один юнит, `--exclude a2-x,…` пропустить юниты в работе.
- `npm test` (Playwright): данные, все экраны 390 px в светлой/тёмной теме, упражнения, домашка, экспорт/импорт/отмена,
  SRS, контраст, офлайн, кнопка «назад».

## Готово
- Каркас, движок упражнений, SRS, все разделы (Wortschatz, Grammatik, Hören, Lesen, Schreiben, Dialoge/Sprechen).
- A1: Hamburg, Berlin, Leipzig — 655 слов, 15 тем грамматики. A2: Köln, Frankfurt, Heidelberg — 631 слово, 15 тем.
  Итого 1286 слов, 30 тем, 397 упражнений грамматики. Korrektorat сделан.
- Prüfung: модельные тесты A1 и A2 (формат Goethe) с таймером, ограничением прослушиваний, автопроверкой Hören/Lesen,
  самооценкой Schreiben/Sprechen и промптом для ИИ.
- Hausaufgaben: конструктор → ссылка → ученик выполняет → отчёт + код R1 → учитель вставляет код → результаты,
  ошибки, слабые темы. Без сервера.
- Озвучка: выбор самого естественного голоса устройства, ручной выбор голоса, чтение по предложениям,
  второй голос в диалогах, подсказки, как установить нейросетевые голоса.
